# Discord update posts

Discord updates must use plain, player-facing language. Describe what users can
do or what feels better. Do not include technical details, code terminology,
file paths, dependency names, test results, or implementation explanations.

For user-visible updates, add one or more single-line `Discord-Update:` notes
to the commit body. Only those explicitly authored notes are posted to Discord.
Keep technical details in the rest of the commit message. Without a public note,
the workflow sends a neutral update notification instead of copying commit text.
